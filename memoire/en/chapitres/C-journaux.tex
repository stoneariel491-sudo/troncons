\chapter{Logs and reproduction of the figures}\label{ann:journaux}

What produces a published number is committed: tools and logs. This appendix says where the logs are and which data each graph reads. Both tables are generated by \fichier{memoire/outils/annexes.py}.

\section{Rebuilding the thesis}

From \fichier{memoire/}, in Git Bash, with MiKTeX (lualatex, biber, latexmk) and Python 3.13 with no dependency:
\begin{lstlisting}[language=bash, numbers=none]
./construire.sh          # figure data, appendices, then both PDFs
./construire.sh en       # one language only
./construire.sh propre   # removes intermediate files
\end{lstlisting}
Each pgfplots graph reads a committed CSV; each TikZ diagram is a file in \fichier{memoire/figures/schemas/}; the figure commands are shared by both languages, which only differ by their texts (\verb|\EF{English}{French}|). Each thesis reads in parallel with the other: same chapters, same labels, same figures.
